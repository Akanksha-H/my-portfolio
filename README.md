# Aakanksha Hedau | Portfolio

A personal portfolio website built to showcase my profile, projects, technical skills, and contact details.

## Overview

This project is a responsive single-page portfolio for a software developer, highlighting:

- About section
- Technical skills and stack
- Featured projects
- Contact information
- Downloadable CV

## Tech Stack

- HTML5
- CSS3
- JavaScript
- Font Awesome icons
- Google Fonts

## Project Structure

```text
Portfolio/
├── index.html
├── css/
│   └── style.css
├── js/
│   └── index.js
├── img/
├── assets/
│   └── Aakanksha_Hedau_CV.pdf

```

## Run Locally

You can open the site directly in a browser:

```bash
start index.html
```

Or serve it locally with a simple HTTP server:

```bash
python -m http.server 8000
```

Then visit:

```text
http://localhost:8000
```

## Features

- Mobile-friendly responsive design
- Smooth navigation and active section highlighting
- Social links for GitHub, LinkedIn, and email
