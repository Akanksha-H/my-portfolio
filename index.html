About Me

I'm a Software Engineer based in Bengaluru, Karnataka, building a career in full-stack development. I recently completed my Post Graduate Diploma in Advanced Computing (C-DAC), deepening my skills in Java Spring Boot, .NET, and containerized deployment with Docker and Kubernetes.

One project close to my heart is Flowflix, an OTT media streaming platform I was frontend lead, built this project using — React.js, contributed Spring Boot backend with JWT/OAuth2 authentication, MySQL data design, and a Jenkins CI/CD pipeline on Docker and Kubernetes.

I love turning ideas into working systems — writing clean, well-tested code, thinking through architecture, and collaborating with teams to ship reliable software.
